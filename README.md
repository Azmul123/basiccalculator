# C Calculator

A simple command-line calculator built using the C programming language. It performs basic mathematical operations on two numbers using `switch-case` statements and a `do-while` loop.

This is one of my beginner C programming projects, created to practice programming fundamentals and understand how different control-flow statements work.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Modulus
- Menu-driven interface
- Continuous calculations using a `do-while` loop
- Exit option
- Basic division-by-zero handling

## Technologies Used

- C
- GCC Compiler
- Standard I/O Library (`stdio.h`)

## Getting Started

### Clone the repository

```bash
git clone https://github.com/Azmul123/basiccalculator.git
```

### Navigate to the project folder

```bash
cd basiccalculator
```

### Compile the program

```bash
gcc calculator.c -o calculator
```

### Run the program

**Windows:**
```bash
calculator.exe
```

**Linux / macOS:**
```bash
./calculator
```

## How It Works

When the program starts, it displays a menu of mathematical operations. The user selects an operation, enters two numbers, and gets the calculated result.

The program uses:

- `switch-case` to handle different operations.
- `do-while` to keep the calculator running.
- `break` to exit the loop when the user selects the exit option.
- Arithmetic operators to perform calculations.
